# MoneyWise — Personal Finance Dashboard

A React + Vite V1 project for tracking personal income, expenses and budgets.

## Features
- Add income and expenses
- Categories and transaction dates
- Live balance, income and expense totals
- Search and filter transactions
- Delete transactions
- Category budgets and progress
- Spending breakdown
- localStorage persistence
- Responsive mobile layout

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The project is ready for Vercel deployment.
